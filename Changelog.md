# 0.0.7

## Изменение статуса коллизии из Ревита

- Статус выбирается в колонке «Статус». Изменения копятся в окне и уходят на сервер коллизий одной пачкой
  по кнопке «Сохранить все» — `POST api/clashes/status`. Автор изменения определяется по учётной записи
  Windows. Контракт запроса: `docs/ClashStatusUpdateApi.md`.
- Новые колонки «Кем изменён» и «Когда изменён» показывают автора и время последнего изменения статуса,
  если сервер их возвращает.
- Внизу окна появилась строка состояния: количество неотправленных изменений, результат отправки и ошибки.
- При закрытии окно предлагает сохранить неотправленные изменения статусов.

## Таблица коллизий

- Кнопка «Колонки» показывает и скрывает любые колонки таблицы.
- Ширину колонок можно менять, потянув за границу заголовка.
- Ширина и видимость колонок запоминаются и восстанавливаются при следующем открытии окна.
- В заголовке отсортированной колонки появился указатель направления сортировки (▲/▼).

## Исправления

- `Juru.RevitPlugins.Core` компилировался против библиотек `dosymep` версии 2020 вместо 2024,
  из-за чего сохранение отчёта падало с `Could not load file or assembly 'dosymep.Revit, Version=2020.2.4.0'`.
